# IronCore Fitness — Mobile App Prototype

**Live Demo → [nsafarova.github.io/ironcore-mobileapp](https://nsafarova.github.io/ironcore-mobileapp/)**

A medium-fidelity interactive prototype built for the IronCore Fitness digital transformation consulting project. Scan or open the link above on any phone — no install required.

---

## What's Inside

Three fully clickable user flows, each mapped to a user story from our requirements document:

| Flow | User Story | Business Case |
|------|-----------|---------------|
| Class Booking | US-01 · Must-Have | 42% of members want mobile booking — highest-demand gap vs. competitors |
| Digital Check-In | US-02 · Must-Have | 33% cite check-in lines as a daily friction point |
| Premium Upgrade | US-07 · Should-Have | Drives $65 → $85/mo ARPU, closing the gap to the $18M revenue target |

---

## Personas Represented

The prototype is built around **Jessica Ramirez** (Busy Professional, 34) — IronCore's primary revenue-driving segment. Design decisions were validated against all three personas: Jessica (efficiency), Tyler Nguyen (engagement), and Linda Chen (simplicity + human connection).

---

## Design Decisions

- **Dark minimal UI** — reduces eye strain in gym environments, signals premium positioning
- **Blue accent (#3B82F6)** — communicates trust and digital health credibility; avoids error-state confusion that red would cause
- **3-tap max for every primary action** — zero-friction requirement from Jessica's adoption barrier
- **"Welcome back." on check-in** — mirrors front desk language to preserve human connection (Linda Chen's core concern)
- **Instructor names visible on every class card** — counters Frank Torres's fear of becoming "just another corporate gym"

Plain HTML · CSS · Vanilla JS — no frameworks, no dependencies, works in any mobile browser.
